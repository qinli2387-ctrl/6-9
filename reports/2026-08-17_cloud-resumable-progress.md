# 云端断点续学

## 基线

- 正式 `/levels/:week` 只在整关提交时写入 `level_progress`；进行中的题目、答案和题号没有云端记录。
- 公网 `/demo` 仍是匿名体验版，使用浏览器 `localStorage`，不属于正式账号同步路径。
- D1、ChatGPT 用户身份和服务端用户隔离已经存在；正式 Sites 项目仍返回 `Sites project not found`，生产跨设备链路尚未可验收。

## 变更

- 新增 `lesson_attempts` 表和 `0006_pale_hellfire_club` 迁移，按用户和关卡保存会话状态、题号、答案、版本和完成时间。
- 新增 `0007_gifted_dreaming_celestial` 迁移，保存题目 ID 快照；动态复习队列变化时不会把旧答案套到新题目上。
- 新增 `/api/lesson-attempts` 的开始和保存接口。所有查询、更新均带认证用户 ID；保存使用版本号，旧设备写入返回 `409`。
- 正式关卡开始时创建或恢复会话，每推进一题先保存；整关提交成功后关闭会话。
- Dashboard 增加云端“继续学习”入口，并将入口放到手机第一屏可见的位置。
- 公网体验版保持本地进度语义，不与正式账号数据混用。

## 失败与修正

- 初次手机验收发现继续入口在 24 周地图之后，已提升到进度概览下方。
- 初次集成断言受 React 服务端 HTML 注释分隔影响，已改为匹配可见语义文本。
- 同时创建会话的唯一索引竞争已使用 `onConflictDoNothing` 处理，并加入并发回归断言。

## 安全检查

- 会话表的读取、更新和完成均使用认证 `userId` 与关卡条件。
- 旧版本更新只能返回当前账号自己的最新会话；跨账号传入会话 ID 不会修改他人记录。
- 题目 ID 和答案在服务端按当前关卡校验；动态复习题目集合变化返回冲突并要求刷新。
- 没有新增密码、API key、服务令牌或 `.env` 文件。

## 尚未验证
